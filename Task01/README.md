# Лабораторная работа №1

Подготовка окружения для выполнения заданий и интерактивной работы с СУБД SQLite.

## Структура исходных данных

### `users.txt`

Содержит сведения о пользователях. Заголовок отсутствует, поля разделены символом `|`.

Порядок полей:

1. идентификатор пользователя;
2. имя и фамилия;
3. адрес электронной почты;
4. пол;
5. дата регистрации в формате `YYYY-MM-DD`;
6. профессия.

Пример строки:

```text
1|Devonte Stamm|marianne.krajcik@bartoletti.com|male|2010-09-19|technician
```

### `occupation.txt`

Справочник профессий пользователей. Каждая строка содержит название одной профессии.

### `genres.txt`

Справочник жанров фильмов. Каждая строка содержит название одного жанра.

### `movies.csv`

Содержит сведения о фильмах. Первая строка содержит заголовки столбцов.

| Столбец | Описание |
| --- | --- |
| `movieId` | Идентификатор фильма |
| `title` | Название фильма и год выпуска |
| `genres` | Жанры фильма, разделённые вертикальной чертой |

### `ratings.csv`

Содержит оценки, поставленные пользователями фильмам. Первая строка содержит заголовки столбцов.

| Столбец | Описание |
| --- | --- |
| `userId` | Идентификатор пользователя |
| `movieId` | Идентификатор фильма |
| `rating` | Оценка фильма |
| `timestamp` | Время выставления оценки в формате Unix timestamp |

### `tags.csv`

Содержит теги, добавленные пользователями к фильмам. Первая строка содержит заголовки столбцов.

| Столбец | Описание |
| --- | --- |
| `userId` | Идентификатор пользователя |
| `movieId` | Идентификатор фильма |
| `tag` | Текст тега |
| `timestamp` | Время добавления тега в формате Unix timestamp |

## Результаты работы

- `ratings_count.txt` — минимальный и максимальный идентификаторы пользователей из файла `ratings.csv`, а также количество строк с этими идентификаторами.
- `sqlite.txt` — номер установленной версии SQLite и доступные режимы вывода консольной утилиты `sqlite3`.
